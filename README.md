
# Sabores del Barrio
1. Instala Node.js LTS.
2. Enciende Apache y MySQL en XAMPP, abre phpMyAdmin e importa `database/schema.sql`.
3. `cd backend` → `npm install` → `npm run dev` (puerto 3001).
4. `cd frontend` → `npm install` → `npm run dev`.
5. Abre el link que muestra la terminal del frontend (normalmente http://localhost:5173).
